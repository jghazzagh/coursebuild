Step by step

Get your page into Brightspace

Choose a method, then work through the steps. Each screen is a simulation you can click, so you can practice before touching your real course. Use Next step to move along. Keep Course Builder and Brightspace open in separate tabs so you can switch between them.

Start with a new, blank content page. This walkthrough adds a complete page. If you already have content to keep, see Update a page you already published instead.

In Course Builder

Select Copy page HTML

Build and check your page first. When it holds your own content, select Copy page HTML near the top of the builder. It copies the whole page for you, so you never select any code yourself.

What to expect: A message confirms the page was copied.

Order matters. Finish your text in Course Builder first, then add images, video, and audio in Brightspace last. Pasting new HTML over a page replaces anything you added there. The Check page button in Course Builder is a good first pass, but it cannot replace reviewing the finished page in your course.

Prefer a file? This method saves your page as its own web page file and adds it to your course. To change it later, edit the page in Course Builder, download again, and upload the new file. Copy and paste keeps the page editable inside Brightspace, so most people prefer it.

In Course Builder

Select Download HTML

Select Download HTML. Course Builder saves a complete web page file named after your page title, usually into your Downloads folder. You do not need Copy page HTML for this method.

Keep your work

Save, reuse, and update

Course Builder autosaves in your browser, but that copy stays on this computer. After building or revising a page, choose Save and manage → Save editable copy (JSON), give the file a useful name, and keep it with your course materials. You never need to open the file yourself.

Come back later

If an autosaved page is waiting when you return to the same browser, select Resume page. Treat an exported project file as your dependable copy.

Another computer or a colleague

Bring or send the exported project file. Open Course Builder and choose Save and manage → Open editable copy (JSON). Autosave and favorites do not travel between computers.

Update a published page

Small wording changes: use Brightspace's regular editing view.

Bigger layout changes: reopen your project in Course Builder, revise it, then replace the page.

Course Builder and Brightspace hold separate copies. Changes made in Brightspace do not return to your Course Builder project, so note any Brightspace-only edits before you replace a page.

Update a page you already published
  1. Keep a copy of the current Brightspace page and any images or text you need. Ask us if you are unsure how.
  2. Bring any changes made only in Brightspace into your Course Builder project.
  3. Copy the revised page and test it on a new blank Brightspace page first.
  4. When you are ready to replace the entire existing page, open it for editing, open its HTML Source Editor, select everything inside that window, and paste the revised copy.
  5. Apply the change, save, and recheck links, media, and activities.

To insert just one block into an existing page, ask us to help with placement. You do not need to work out where the code goes.

Quick fixes

What are you seeing?

I see code instead of my page, or nothing happened when I pasted.

Inside the source window, code is expected. Apply the change to return to the editor. If code shows on the saved page, it was probably pasted into the regular editing area. Try a new blank page and paste into the HTML Source Editor, and keep any existing work until the new copy looks right.

If pasting does nothing, go back to Course Builder and select Copy page HTML again. Switch to Brightspace, click inside the source window, and press Ctrl + V (Mac: Cmd + V). Still stuck? Ask us.

I can't find the HTML Source Editor button.

Make sure you are editing a content page, not just viewing it. The control may appear only when the toolbar is expanded, so try the three dots or the fullscreen button. D2L's editor guide shows the control. If your screen looks different, send us a screenshot of the toolbar.

The page looks different, or a button or activity does not respond.

Save the page and test it outside the editing area first. Confirm you used Copy page HTML so the whole page was copied, then try it on a new blank page. If an activity works in Course Builder but not on the saved Brightspace page, tell us the block name and where you pasted it. You do not need to troubleshoot the code. Practice blocks do not send scores to the Brightspace gradebook.

An image still says placeholder.

The placeholder marks a spot for your own image. Add the image in Brightspace's regular editor, or paste an image address if the block has an Image link field. Include a useful image description. If you are unsure, send us the block name.

Brightspace shows an old version, or I changed the wrong block.

The two copies do not update automatically. Copy the revised page again and follow Update a page you already published. In Course Builder, use Undo to step back, or reopen your project with Save and manage → Open editable copy (JSON). If you changed the Brightspace copy, stop before saving unwanted changes and ask for help.
