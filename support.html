Quick guides

Build, check, and publish

Step 1

Set up the page

Choose a template, write the page label and Heading 1, select a title style, and optionally add an image URL. Page Setup collapses after your first block so it stays out of the way.

Step 2

Add and edit blocks

Open a category in the left panel and add blocks. Use the Add block here bars in the preview to insert between blocks, then drag or use the arrow controls to reorder, and the copy control to duplicate.

Step 3

Check accessibility

Use the Check page button to scan for heading order, color contrast, placeholder text, and empty links. Keep meaningful link text, useful image descriptions, and content that does not rely on color alone.

Step 4

Move it to Brightspace

Copy the page HTML, paste it into the Brightspace HTML source editor, save it, and preview the result as a learner.

Save and reuse

Keep your work with Export and Import

Export JSON

The Export JSON button downloads your whole page as a small .json project file. This is separate from the Brightspace HTML. The HTML is the finished page you paste into a course, and the JSON is the editable source you can reopen later.

Import JSON

The Import JSON button loads a .json file back into the builder with every block intact, ready to keep editing. Use it to reuse a strong page next term, or to open one a colleague shared with you.

Autosave and Resume

The builder autosaves to this browser as you work. When you return, choose Resume to pick up where you left off. Autosave stays in one browser, so use Export JSON to move a page between computers or people.

The Widget Builder has the same Export JSON and Import JSON buttons, so your team can build a shared set of standard homepage widgets and hand them out as files.

Frequently asked questions

Answers before the panic button

Do I need to know HTML?

No. The Page Builder handles the HTML while you edit the page through form fields and a visual preview.

Can I save a page and come back to it later?

Yes. The Page Builder autosaves in your browser and shows a Resume option when you return. For a copy you can keep or move between computers, use Export JSON to download the page as a file, then Import JSON to open it again.

How do I share a page with a colleague?

Use Export JSON to download the page as a .json file and send it to them. They open the Page Builder, choose Import JSON to load it, and customize their own copy. This shares the editable source, not just the finished HTML.

What if I delete or change the wrong block?

Use the Undo button, or press Ctrl+Z (Cmd+Z on a Mac), to step back. You can also duplicate a block with its copy control instead of rebuilding it.

Can I edit the page after copying it?

Yes. The output is standard HTML with inline styles, so it can be revised in Brightspace or rebuilt in CourseMaker.

Will this work with the New Content Experience?

The generated pages use responsive, self-contained HTML intended to display inside Brightspace content pages. Always preview the finished page in your course.

Can I use other colors?

The builder uses approved MCC colors. Keeping the palette limited supports brand consistency and accessible contrast.
