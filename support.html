CourseMaker support

Create your page. Copy it. Paste it into Brightspace.

You do not need to write or understand HTML. CourseMaker creates the code for you. You only need to know which button copies it and where to paste it.

Keep CourseMaker and your Brightspace course open in separate tabs so you can switch between them.

Start here

Put your first page into Brightspace

Start with a new, blank content page. This walkthrough adds a complete page. If you already have content to keep, use the existing-page instructions instead.

  1. In CourseMaker

    Build and check your page

    Open Start a page to choose a template. Use Page Header for the page title and colors. Add blocks, select them in the page preview, and edit their details. Select Check page and review the results.

    Ready to continue: Your page contains your own directions and content.

  2. In CourseMaker

    Select Copy page HTML

    Use Copy page HTML near the top of the builder. This copies the whole page for you. You do not need to select the code yourself.

    For this walkthrough, you do not need Download HTML or Export JSON.

    What to expect: A message confirms the page was copied.

  3. In Brightspace

    Create a blank page

    Open Content, select the unit or lesson where the page belongs, then choose Create New → Page. Enter the page title.

    What to expect: An editing area with a toolbar.

  4. In Brightspace

    Open the HTML Source Editor

    Find the HTML Source Editor control, usually shown as </>. If needed, expand the toolbar or use Fullscreen. Hover over controls to read their names.

    What to expect: A plain-text window. Some starter code may already be there.

  5. In the source window

    Paste the copied page

    Click inside the source window. For this new blank page only, select its starter code with Ctrl + A (Mac: Cmd + A), then paste with Ctrl + V (Mac: Cmd + V).

    What to expect: Lots of code. That is normal. You do not need to read or change it.

  6. Back in Brightspace

    Apply, save, and check

    Apply the source-window change, then save the Brightspace page. Reopen the saved page and test its links and activities.

    Success looks like: The formatted page appears instead of code.

Brightspace reference: Create a page in the New Content Experience and Find the HTML Source Editor. Your course’s controls may look slightly different.

Quick fixes

What are you seeing?

My page shows code instead of the design.

If you are still inside the source window, seeing code is expected. Apply the change to return to the regular editor. If code appears on the saved page, it may have been pasted into the regular editing area. Try the walkthrough on a new blank page and paste into HTML Source Editor. Keep any existing work until your new copy looks right. Still stuck? Ask us.

I can’t find the HTML Source Editor button.

Make sure you are editing a content page, rather than just viewing it. Look for the source-editor control; it may become available when the editor is expanded. D2L’s editor guide shows the control and editor views. If your screen looks different, send us a screenshot of the toolbar.

Nothing happened when I pasted.

Return to CourseMaker and select Copy page HTML again. Switch to Brightspace, click inside the source window, and use the paste keyboard shortcut. On Windows, use Ctrl + V; on a Mac, use Cmd + V. If copying produces no confirmation, contact support.

The page looks different after saving.

Open the saved page outside the editing area first. If the layout still looks wrong, confirm that you copied the whole page with Copy page HTML. Try it on a new blank page without adding another template in Brightspace. If the problem continues, send us screenshots of the CourseMaker preview and the saved page through support.

The buttons or activities aren’t responding.

Save the page and test it outside the editor. If the same activity works in CourseMaker but not on the saved Brightspace page, tell us the block name and where you pasted it. You do not need to troubleshoot its code. Practice blocks do not send scores to the Brightspace gradebook.

My image still says placeholder.

The placeholder marks a spot for your own image. Follow that block’s image instructions in Brightspace’s regular editor, or supply an image address if the block has an Image URL field in CourseMaker. Include a useful image description. If you are unsure how to replace the placeholder, send us the block name.

I changed CourseMaker, but Brightspace shows the old version.

The copies do not update automatically. Copy the revised page again and follow Update an existing page. Keep any changes made only in Brightspace before replacing its content.

I changed or deleted the wrong block.

Use Undo in CourseMaker to step back. For a page from a previous session, reopen your saved project with Import JSON. If you changed the Brightspace copy, stop before saving unwanted changes and ask for help if you are unsure how to recover.

Before students use it

Give the finished page a quick check

  • Replace example text, image placeholders, and sample links.
  • Check dates, directions, and the location of any assignment or discussion.
  • Open links and confirm students can access their destinations.
  • Check image descriptions, video captions, and audio transcripts.
  • Try interactive activities on the saved page, including with a keyboard.
  • Review the page as a learner and confirm its visibility settings.

Check page is a helpful first pass. It can flag common issues in CourseMaker, but it cannot replace reviewing the finished page in your course.

Keep your work

Save a copy you can edit later

Select Export JSON after building or revising a page. Give the downloaded file a useful name and keep it with your course materials. You never need to open or edit the file yourself. CourseMaker reads it for you.

Come back later

CourseMaker also autosaves in the current browser. If a saved page is available when you return, select Resume page. Keep an exported project as your dependable copy.

Use another computer

Bring your exported project file with you, open CourseMaker, and select Import JSON. Browser autosave and favorites do not travel between computers.

Share with a colleague

Give them the exported project file. They select Import JSON in CourseMaker and customize their own copy. No one needs to read the file’s contents.

Making changes

Update a page after publishing

Small wording changes

Use Brightspace’s regular editing view to revise a sentence, fix a typo, or adjust a link. Save and check the result. You do not need to open the code to change ordinary text.

Bigger layout changes

Open the saved CourseMaker project with Import JSON. Add, remove, or rearrange blocks there. Export an updated project before transferring the revised page.

CourseMaker and Brightspace are separate copies. Changes made in Brightspace do not return to your CourseMaker project. Keep track of those edits before replacing a page.

Update an existing page without losing content
  1. Keep a copy of the current Brightspace page and any images or text you need. Ask support if you are unsure how.
  2. Bring any changes made only in Brightspace into your CourseMaker project.
  3. Copy the revised page and check it on a new blank Brightspace page first.
  4. When you are ready to replace the entire existing page, open that page for editing, open its HTML Source Editor, select the content inside that source window, and paste the revised copy.
  5. Apply the change, save, and recheck links, media, and activities.

If you only want to insert one block into an existing page, ask us to help with placement. You do not need to work out where to insert code.
