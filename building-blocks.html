Start with the learning need

Choose a block that makes the content clearer, easier to navigate, or more useful for practice. This guide covers all 53 available blocks in the same 10 categories and order used in the Page Builder. The five newest blocks are marked New.

In the builder, select Preview to try a sample before adding it. Use Favorite to save shortcuts; Favorites & recently used keeps your choices in the current browser. Starter templates, titles, banners, and accent colors are under Page Header. Use the Templates page to compare complete layouts. Fields with a formatting toolbar support bold, italic, underline, strikethrough, superscript, and subscript.

Text & Layout

Core content and page structure

Intro text

What it does: Adds a larger opening paragraph that orients students. Includes the formatting toolbar (bold, italic, underline, strikethrough, superscript, subscript).

Use it when: You need a brief purpose statement, overview, or welcome at the top of a page.

Try this block

Section heading

What it does: Creates an H2, H3, or H4 heading with MCC styling.

Use it when: A page changes topic or students need clear landmarks for scanning and screen-reader navigation.

Try this block

Paragraph

What it does: Adds standard body text in the default Lato 19px style. Includes the formatting toolbar.

Use it when: You are explaining concepts, giving directions, or adding normal course content.

Try this block

Bullet list (1–10)

What it does: A configurable bulleted list with six marker styles (round, square, bar, check, arrow, or numbered) and three row styles (plain, divided, or boxed).

Use it when: A checklist doesn't fit the tone, or you want a numbered or icon-style list instead of the default bar bullets.

Try this block

Blockquote

What it does: Formats a quotation with its source or speaker.

Use it when: A source, expert voice, or student perspective directly supports the lesson.

Try this block

Divider

What it does: Adds a simple horizontal separator in the selected color.

Use it when: Two page regions need a visual break but a new heading would not add meaning.

Try this block

Two-column content

What it does: Places two related content sections side by side and stacks them on smaller screens.

Use it when: Comparing two ideas, presenting paired examples, or separating two equally important content areas.

Try this block

Instructor Information

Contact details, introductions, and instructor guidance

Instructor insight

What it does: Pairs an instructor image with a short practical tip. The image can be left, right, or removed entirely for a text-only layout, with an adjustable image width. Includes the formatting toolbar.

Use it when: Your experience, warning, example, or coaching can help students apply the content.

Try this block

Instructor information

What it does: Combines a portrait, contact information, office hours, and an introduction. Supports the same image placement and width options as Instructor insight.

Use it when: Building instructor presence on a welcome page or Meet Your Instructor page.

Try this block

Course Organization

Objectives, directions, schedules, and lesson flow

Assignment brief

Layout idea: Use Paragraph and Section heading blocks for Purpose, Your task, How to submit, and Success criteria. Add Button links for the assignment destination.

Build this layout by combining existing blocks.

Start with Paragraph

Learning objectives

Layout idea: Use the Bullet list block with numbered circles for measurable objectives. Add practice and assessment connections in each item or a nearby paragraph.

Build this layout by combining existing blocks.

Start with Bullet list (1–10)

Lesson wrap-up

Layout idea: Combine Paragraph, Callout box, and Button links blocks for key takeaways, a reflection question, and the next activity.

Build this layout by combining existing blocks.

Start with Paragraph

Checklist

What it does: Presents related points as a clean, styled list. This version is static, not clickable. For checkboxes students can tick off, use the Interactive checklist instead.

Use it when: Order does not matter and students need to scan or review several concise items, such as key takeaways or objectives.

Try this block

AI policy block

What it does: Displays MCC red, yellow, or green AI-use expectations.

Use it when: Students need explicit assignment-level guidance about whether and how generative AI may be used.

Try this block

Due date reminder

What it does: Shows a labeled due date and short note, with an optional live countdown timer. When the countdown is on, Check Page confirms the date is valid and not already in the past.

Use it when: You want a deadline to stand out on the page. If you turn the countdown on, update the date each term or it will read as overdue on day one.

This reminder does not set or update due dates in Brightspace.
Try this block

Weekly rhythm stepper (2–8)

What it does: A Previous and Next stepper with a progress bar, for walking through a repeating structure.

Use it when: Introducing the recurring pattern students will follow every week or module, such as Read, Watch, Do.

Try this block

Interactive checklist

What it does: Gives students a checklist with a live count of items completed.

Use it when: A module or weekly page has several tasks students want to check off as they go. Progress is not saved between visits, so treat it as a personal tracker, not a graded record.

Try this block

Colored course cards (1–6)

What it does: A row of colored cards alternating between the block's accent and a paired color, evenly distributed regardless of count.

Use it when: Introducing a short set of parallel ideas, such as course outcomes or unit highlights.

Try this block

Callouts & Key Ideas

Reminders, explanations, and important takeaways

Callout box

What it does: Highlights information in one of nine styles: Information, Important notice, Tip, Example, Research and sources, Reflection, Idea, Pause, or Custom icon. Includes the formatting toolbar.

Use it when: Students could miss a critical reminder, exception, warning, example, or cited source in normal text.

Try this block

Colored block

What it does: Places a heading and text on a selected MCC color. Includes the formatting toolbar.

Use it when: You need to emphasize a takeaway, definition, summary, or transition without adding an interaction.

Try this block

Media & Visuals

Images, video, audio, and visual stories

Story or image carousel

What it does: Moves through two to ten text or image slides.

Use it when: Telling a short story, walking through visual examples, or presenting a focused image sequence.

Try this block

Image

What it does: Adds a responsive image with alternative text and an optional caption.

Use it when: A visual example, diagram, photograph, or artifact directly supports the learning objective.

Try this block

Video

What it does: Embeds a YouTube video or creates a Brightspace or YuJa placeholder.

Use it when: Motion, demonstration, explanation, or modeled performance communicates better than text alone.

Try this block

Audio note with transcript

What it does: Adds an audio player for a hosted file such as a YuJa or mp3 link, with an expandable transcript field beneath it. Supply the full transcript.

Use it when: Adding your voice for a welcome, weekly intro, or feedback. Provide an accurate transcript for students who cannot hear or play the audio.

Try this block

Before and after compare

What it does: Toggles between two labeled images, each with its own description.

Use it when: Showing change over time or contrasting two states, such as before and after, healthy and affected, or draft and revision.

Try this block

Content image with text

What it does: Places an instructional image beside related explanatory text, with adjustable image placement and width, or no image at all. Includes the formatting toolbar.

Use it when: The visual and explanation should be understood together, such as a diagram, example, artifact, or process image.

Try this block

Reveal & Explore

Optional details and focused exploration

Annotated reading

What it does: Turns marked phrases in a passage into buttons that reveal an annotation when selected.

Use it when: Guiding close reading of a passage, primary source, snippet of code, or any text where specific phrases deserve explanation.

Try this block

Accordion (1–6)

What it does: Opens and closes one to six sections.

Use it when: Optional details, examples, FAQs, or supporting explanations would otherwise make the page too long.

Try this block

Tabbed sections

What it does: Switches among two to five related panels in a horizontal or vertical layout.

Use it when: Students need to compare a small set of parallel categories. Avoid tabs for steps that must be completed in order.

Try this block

Flip card

What it does: Reveals the back of a card when selected.

Use it when: Practicing terms, definitions, brief questions, examples, or paired concepts.

Try this block

Click and reveal

What it does: Hides one explanation until a learner selects a reveal button.

Use it when: Prompting prediction, reflection, or an answer before showing the instructor explanation.

Try this block

Timelines & Processes

Sequence, chronology, and procedures

Timeline

What it does: Displays events or steps in a visible vertical sequence.

Use it when: Order, chronology, or progression matters and all details should remain visible.

Try this block

Interactive timeline

What it does: Reveals milestone details when students select a date or stage.

Use it when: A process or historical sequence has several milestones that deserve focused exploration.

Try this block

Interactive path timeline (1–8)

What it does: A clickable horizontal path where selecting a marker reveals its details below.

Use it when: Showing a multi-stage path, such as a project workflow or the arc of a semester, at a glance.

Try this block

Guided stepper

What it does: Lets students move through two to six labeled steps one panel at a time.

Use it when: Teaching a workflow, method, procedure, or sequence that benefits from focused stages.

Try this block

Step flow boxes (2–6)

What it does: Colored boxes connected by arrows, showing a short linear sequence. Includes the formatting toolbar on the step text.

Use it when: Modeling a short reflection or process pattern, such as What, So What, Now What.

Try this block

Practice & Feedback

Questions, practice, reflection, and criteria

Discussion prompt

Layout idea: Use Paragraph and Section heading blocks for the opening question, initial-post expectations, reply guidance, and evaluation criteria. Students post in Brightspace Discussions.

Build this layout by combining existing blocks.

Start with Paragraph

Multiple choice question

What it does: Creates a full question form with two to six answers, a selected correct answer, feedback for every response, and a Check My Answer button. Feedback text includes the formatting toolbar.

Use it when: Learners should commit to one answer before receiving targeted corrective or reinforcing feedback.

Use this block for new knowledge checks. Older saved pages with the original Knowledge check block still import and remain editable. Responses are not saved or sent to the Brightspace gradebook.
Try this block

Drag and drop sorting

What it does: Lets students sort items into two or three categories by dragging, or by selecting an item and then a category, with a check button and feedback.

Use it when: Students should practice classifying or grouping. The select-then-choose method keeps it usable on keyboards and touchscreens, so lead with that in your directions.

Try this block

Sequence ordering

What it does: Presents shuffled steps that students reorder with up and down buttons, then check against the correct sequence.

Use it when: Order matters, such as a procedure, method, or chronology. Enter the steps in the correct order and the block shuffles them for students.

Try this block

Matching memory grid

What it does: Hides terms and definitions on cards that students flip to find matching pairs.

Use it when: Practicing paired terms and definitions or cause-and-effect pairs.

Try this block

Estimation slider

What it does: Asks students to predict a value on a slider, lock in their guess, then reveals the actual answer and how far off they were.

Use it when: You want students to commit to a prediction before seeing data. Follow the reveal with an explanation of the answer and its source.

Try this block

Self-assessment rubric

What it does: Has students rate their confidence on several criteria and returns a personalized list of what to review.

Use it when: Encouraging honest self-assessment and metacognition. Nothing is graded, recorded, or saved between visits.

Try this block

Grading rubric

What it does: Creates a color-graded rubric table from performance levels and criteria you enter as pipe-separated text.

Use it when: You want a properly formatted rubric on the page without hand-building a table in Brightspace's editor.

Display only. This table does not create a Brightspace rubric or record grades.
Try this block

Scenarios & Examples

Applied judgment and modeled problem-solving

Decision scenario

What it does: Presents a realistic situation, response choices, and feedback for each choice. Feedback text includes the formatting toolbar.

Use it when: Students should practice judgment, consider consequences, or apply a principle in context.

Try this block

Scenario reveal boxes (1–6)

What it does: Scenario cards with a reveal button and a verdict-style answer, such as pitfall versus best practice. Explanation text includes the formatting toolbar.

Use it when: Running a quick check-your-judgment activity across several short scenarios.

Try this block

Worked example (fading steps)

What it does: Shows a fully worked problem with the later steps hidden behind try-then-reveal buttons. Step content includes the formatting toolbar.

Use it when: Teaching problem-solving. Students study the early steps, then attempt the rest before checking.

Try this block

Resources & Data

Support links, sources, and structured information

Student support

Layout idea: Combine Paragraph and Button links blocks for service descriptions, verified contact information, and resource links.

Build this layout by combining existing blocks.

Start with Button links (1–4)

Reference list

What it does: Formats a list of citations with a hanging indent, one entry per line.

Use it when: A page needs a reference or works-cited list. Use your own citation style; the block does not generate one for you.

Try this block

Key statistic

What it does: Displays one large, bold statistic with a short explanation. Includes the formatting toolbar. The source field is not technically required, but Check Page will flag a statistic with no source.

Use it when: Highlighting a single compelling number. If you cannot cite where a number comes from, do not use this block for it.

Try this block

Table

What it does: Creates an accessible table with a caption, column headings, and rows.

Use it when: Students need to compare values across categories or look up structured information. Do not use tables only for visual layout.

Try this block

Scope rating cards (1–6)

What it does: Cards with a filled-dot rating (such as effort or scope) beside a heading and description. Includes the formatting toolbar on the card text.

Use it when: Comparing options that differ by size, effort, or ambition, such as project choices or extension activities.

Try this block

Button links (1–4)

What it does: Creates one to four prominent links in a responsive layout.

Use it when: Students need clear calls to action such as opening an assignment, discussion, reading, or external resource.

Try this block
